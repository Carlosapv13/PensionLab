# PensionLab

## Descripción

PensionLab es una aplicación web diseñada para ayudar a los colombianos a planificar su pensión mediante simulaciones, cálculos y asistencia con inteligencia artificial.

## Objetivo

Permitir que una persona pueda responder preguntas como:

- ¿Cuánto podría recibir de pensión?
- ¿Me conviene aumentar mi IBC?
- ¿Qué pasa si cotizo un año más?
- ¿Cuándo completaré las semanas requeridas?

## Tecnologías

- React
- Node.js
- PostgreSQL
- Claude AI
