# IA en el desarrollo de PensionLab

Esta sección documenta el uso de inteligencia artificial como parte del proceso de
desarrollo de PensionLab — metodología, principios, límites, y observaciones del
proceso. No documenta aprendizaje personal (eso se mantiene fuera de este
repositorio) ni funcionalidades de IA dentro del producto PensionLab en sí, que
todavía no están diseñadas (ver la nota correspondiente en
`principios-y-limites.md`).

## Contenido

- [`metodologia-de-desarrollo-con-ia.md`](./metodologia-de-desarrollo-con-ia.md) —
  cómo se ha trabajado: el patrón proponer → documentar → aprobar → implementar,
  roles, y los estándares de documentación adoptados durante el proyecto.
- [`principios-y-limites.md`](./principios-y-limites.md) — principios de
  gobernanza sobre el uso de IA en el proyecto, y los límites de su autonomía.
- [`estados-observados.md`](./estados-observados.md) — registro empírico de
  estados de la interfaz de Claude observados durante el desarrollo. No es
  documentación oficial de Anthropic.

## Relación con el resto de la documentación

| Carpeta | Responde a |
|---|---|
| `docs/tecnico/` | Qué se construyó |
| `docs/gestion/` | En qué estado está el proyecto |
| `docs/ia/` | Cómo se hace el trabajo cuando hay IA involucrada, y bajo qué principios |

Ninguna decisión de arquitectura o de producto se documenta aquí — esas viven en
`docs/tecnico/` y `docs/gestion/`, con su propia sección de "Decisiones". Esta
carpeta documenta el proceso de colaboración, no su sustancia.
