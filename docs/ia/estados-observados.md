# Estados observados de la interfaz de Claude durante el desarrollo

## Objetivo

Registrar, de forma objetiva y empírica, estados o comportamientos de la interfaz
de Claude Code que hayan sido **relevantes para el desarrollo de PensionLab** —
no un inventario exhaustivo de todo lo observado.

**Criterio de inclusión:** un estado observado se documenta aquí únicamente si dio
lugar a una conversación técnica, una decisión metodológica, o una reflexión
concreta sobre cómo se trabaja con IA en este proyecto. Una lista completa de
estados de la interfaz, sin ese criterio, pertenece a investigación y aprendizaje
personal — se mantiene fuera de este repositorio a propósito.

**Esto no es documentación oficial de Anthropic ni de Claude Code.** Son
observaciones hechas durante este proyecto, en un momento y una configuración
específicos — pueden estar incompletas, ser propias de esta instalación, o quedar
desactualizadas si la herramienta cambia. Para documentación oficial, referirse a
las fuentes de Anthropic.
